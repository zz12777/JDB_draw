# 交大盃抽籤系統

交大盃全國大專校院桌球錦標賽的抽籤網頁：上傳報名表單回應，校正名單，規劃籤表，同校分開抽籤，下載完成籤表 Excel。

網頁：https://zz12777.github.io/JDB_draw/

## 使用流程

1. **上傳表單回應**：從 Google 試算表「檔案 > 下載 > Microsoft Excel (.xlsx)」，男子組、女子組、社會組各一份。用 .xlsx 才保留刪除線（整列劃掉的回應預設不採用，格子裡劃掉的名字自動拿掉）。
2. **名單校正**：檢查各項目名單、統一校名、加入地主隊與保留名額、設定種子籤號。可下載抽籤順序表。
3. **籤表規劃**：個人賽切成數個分區，每區一張 X 單敗（2 到 32）；團體賽設定每組隊數與組數。可先下載空白籤表檢查。
4. **抽籤**：一鍵抽籤，可重抽、可手動對調籤位，抽完自動檢查同校分布。亂數代碼可重現結果。
5. **下載完成籤表**：各項目的 Excel 籤表與抽籤結果。

進度存在瀏覽器裡，換電腦或交接時用「匯出專案檔／匯入專案檔」。

## 資料安全

所有處理都在瀏覽器內完成，報名資料不會上傳到任何伺服器。`.gitignore` 排除所有 csv、xlsx、json，請不要把報名資料放進這個 repo。

## 規則摘要

- **同校分開**：學校依人數由多到少處理，每間學校沿著籤表樹由上往下平均分配（上下半區、四分之一區…），同校越晚相遇越好。種子先固定。
- **X 單敗結構**：沿用「(個賽)4-32單敗_直式A4交大盃專用.xlsm」的資格賽位置（21、23 單敗範本缺一個籤位，已依規律補正），見 `js/bracket.js`。
- **場次編號**：個人賽從最深的一輪開始，同一輪由上往下、跨分區連續編；團體賽一輪一輪、A 組到最後一組。中文數字規則同舊 Excel 公式（二一、六五、一〇一）。

完整規格見 `docs/spec.md`。

## 開發

純靜態網頁，沒有建置步驟。ExcelJS 從 cdnjs 載入。

```
python3 -m http.server   # 本機預覽
node tests/draw.test.js <順序表 json>   # 抽籤測試（需要測試資料，不在 repo 內）
```
